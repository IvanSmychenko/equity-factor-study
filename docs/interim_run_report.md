## 2. Идентификация дефекта сплита VTBR (A0)

### 2.1. Симптом (исходный)
- В отчёте `audit`: **«Корпоративных событий: 0»**; `corporate_actions.csv`
  отсутствовал.
- Единственный инструмент с аномальным разбросом цены — **VTBR**:
  `максимум/минимум = 7451` (у остальных 2–296).

### 2.2. Причина
У VTBR цена **двух масштабов**:
- с 2013-07-01 до **08.07.2024** — ~**0.02 руб.**;
- с **15.07.2024** — ~**52–100 руб.**

Между датами месячный подъём цены посчитан как 92.95 / 0.02 ≈ ×4647 →
фантомная цель **4626.25 руб.** (строка `VTBR 2024-06-01`). Это **обратный
сплит / консолидация** — не настоящая доходность.

### 2.3. Механизм искажения (уточнённый диагноз)
Арифметический вклад выброса (~2.25e5) **не** доминирует в MSE (3.5e8)
напрямую. Механизм — **загрязнение коэффициентов OLS рычаговым наблюдением**:
пока наблюдение находится в обучающих окнах, коэффициенты искажаются, что
делает результат полезности факторов недостоверным.

### 2.4. Подтверждение A0
Исключение VTBR из маски (диагностика): MSE=0.0091, MAE=0.069; полезность
факторов всем в диапазоне −0.5%..−1.9% (физиологический масштаб), но знаки
остались отрицательными (артефакт породил гигантские значения, а не ложный знак).

## 5. Устранение дефекта сплита VTBR (шаги A0–A5)

### A1 — обязательный вход корпоративных действий
`load_corporate_events` при отсутствии файла теперь **бросает ошибку**, а не
возвращает пустую таблицу «событий нет». Пустая таблица допустима только при
существующем файле без событий. Приёмка и панель проверяют наличие
обязательных входов: отсутствие любого делает выполнение невозможным.

### A2 — сбор корпоративного события
Проверены все публичные маршруты ISS MOEX (`corporate-actions`, `actions`,
`agreements`, `bondization`, `boards`, полный `securities`, история) — **ни один
не содержит корпоративные действия для акций**. Машинный маршрут недоступен,
поэтому по A2 событие собрано **полуручно**: команда `collect-events`.

Событие зафиксировано в `data/interim/corporate_actions.csv`:

```
secid,date,event_type,coef,source,retrieved_at
VTBR,2024-07-15,split,4663.8,computed_from_moex_history,2026-10-24
```

Коэффициент 4663.8 = 92.95 / 0.01993 (последняя официальная цена до события
08.07.2024 → первая после 15.07.2024).

### A3 — корректировка ряда официальным коэффициентом
`adjust_prices_for_splits` приводит цены к единому масштабу: для дат до события
`close × coef`. Правка применяется **к копии данных** (исходник не изменён) и
**официальным коэффициентом**, а не порогом. Панель получает события и
применяет корректировку перед построением.

### A4 — пересборка и повторная оценка
Панель пересобрана (1 530 строк, s0 = 2014-05). Манифест содержит запись о
корректировке. Приёмка — все PASS, «Итог: принято».
