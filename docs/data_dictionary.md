# Словарь данных итоговой панели

Итоговый артефакт — файл `monthly_panel.csv`, содержащий ровно одну строку на
пару «инструмент — календарный месяц». Дубликаты по этой паре запрещены и
проверяются программно. Панель сопровождается файлом `dataset_manifest.json`.

## Схема панели

| Поле | Тип | Единица | Правило формирования |
|---|---|---|---|
| `secid` | строка | — | Код инструмента в терминах источника |
| `month` | дата | — | Первый день календарного месяца наблюдения |
| `price_date` | дата | — | Дата последней допустимой цены закрытия месяца |
| `month_end_price` | число | рубли | Цена закрытия на `price_date` |
| `return_1m` | число | доля | Цена месяца `t` к цене `t−1` минус единица |
| `momentum_prev_3m` | число | доля | Цена месяца `t−1` к цене `t−4` минус единица |
| `volatility_3m` | число | — | Стандартное отклонение дневных доходностей за три календарных месяца |
| `key_rate_pct` | число | % годовых | Действующая ключевая ставка на последний торговый день месяца |
| `key_rate_change_pp` | число | п.п. | Разность действующих значений на конец смежных месяцев |
| `target_return_next_1m` | число | доля | Цена месяца `t+1` к цене месяца `t` минус единица |
| `quality_flags` | строка | — | Перечень пометок через точку с запятой; пусто, если замечаний нет |

## Правила

* **Дубликаты** по паре «инструмент — месяц» запрещены.
* **Пропуски** в числовых полях допустимы только при непустом значении
  `quality_flags`, указывающем причину.
* **Целевая переменная** последнего месяца периода наблюдения остаётся пустой,
  поскольку следующий месяц ещё не наблюдён; такие строки не считаются
  оценёнными прогнозами.
* **Первый месяц с полным набором признаков** (`s₀`) определяется по всем пяти
  признакам (связывающее ограничение — моментум); первые месяцы ряда, где
  моментум и волатильность недоступны, помечаются в `quality_flags`, а не
  рассчитываются по неполному окну.

## Файл манифеста `dataset_manifest.json`

Манифест фиксирует происхождение панели и содержит:

* версию протокола;
* период наблюдения;
* список инструментов;
* перечень использованных исходных файлов с их контрольными суммами;
* версию кода и версию зависимостей;
* дату построения.

Манифест должен позволять восстановить, из каких именно исходных файлов
получена панель, вплоть до контрольных сумм каждого файла.
